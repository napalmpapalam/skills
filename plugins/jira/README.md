# jira

Jira conventions for Claude Code.

## Skills

- `/dd:jira:ticket` — draft a ticket in the team's format, then create it after your yes. One ticket gets the full form (TLDR / Info / Definition of Done / Not in this task). A scope breakdown — a board or a plan into epics and tasks — goes through a plan doc in `~/.context/` and one iteration per epic, with the keys written back.

All ticket text is in Simplified Technical English (ASD-STE100), in the voice of `references/voice.md`.
