# Sentence shape

Write every sentence in Simplified Technical English (ASD-STE100). Applies to chat,
commits, docs, comments, PR text.

- **One idea per sentence, ~20 words.** Split a long sentence into two. Never drop a
  causal link to hit the number — more sentences, not fewer ideas.
- **Active voice.** Name the actor: "the hook injects context", not "context is injected".
- **One word per meaning.** Pick a term and reuse it. Don't vary "skill" / "plugin" /
  "component" for the same thing to avoid repetition.
- **The simplest precise word.** "cut" not "condense", "use" not "leverage", "so" not
  "in order to". Would the plain word change your meaning? If no, use it.
- **No idioms, no phrasal verbs.** "start" not "kick off", "delete" not "get rid of".
- **Keep the articles.** "the cache is stale", not "cache is stale".
- Technical terms stay exact — idempotent, race condition, deadlock. Simplify the
  sentence, not the vocabulary that carries meaning.
